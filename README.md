# Weazel News V4 — CMS RP citoyen

Fonctionnalités :
- comptes citoyens
- comptes journalistes/admin
- dépôt d'annonces citoyennes
- validation / refus des annonces par la rédaction
- actualités + articles
- breaking news
- notifications Discord
- calendrier des événements
- galerie photo
- réactions/commentaires
- offres d'emploi
- espace rédaction / CMS
- statistiques
- upload d'images
- gestion utilisateurs et contenu

Installation :
1. Node.js 18+
2. npm install
3. copier .env.example en .env
4. définir SESSION_SECRET
5. définir les Webhooks Discord si souhaité
6. npm start
7. http://localhost:3000

Le compte admin est créé au premier démarrage avec ADMIN_EMAIL / ADMIN_PASSWORD.
